# Paws Off Audio Processing Pipeline

This document records the exact offline generation, filtering, splicing, and loudness-normalization pipelines used to build the spoken voice announcements (`public/voice/`), the sampled SATB choir (`public/choir/`), and the 9 sampled acoustic instruments (`public/samples/`). Keeping these parameters pinned ensures future clips and instruments drop in with matched tone and volume.

---

## Part 1: Voice TTS Generation & Mastering Pipeline

All 73 pre-rendered speech clips in `public/voice/*.mp3` are generated by [`scripts/generate_voice_clips.py`](../scripts/generate_voice_clips.py) using Microsoft Edge Neural TTS and broadcast-mastered with FFmpeg + a custom ITU-R BS.1770 K-weighted perceptual loudness controller.

### 1.1 Synthesis Settings

| Parameter | Value | Notes |
| --- | --- | --- |
| TTS Engine | `edge-tts` (`uvx --from edge-tts`) | Run transiently via `uvx` with no Python deps committed |
| Voice | `en-US-AvaNeural` | Natural conversational timbre |
| Speaking Rate | `-12%` | Slightly relaxed pacing for ear-training recall |
| Pitch Offset | `-3Hz` | Subtle warmth without artificial pitch artifacts |
| Text Punctuation | Trailing period `.` on all phrases | Produces a natural falling cadence |
| Catalog | 73 clips (`VOICE_CLIPS`) | 12 keys, 14 triads, 8 sevenths, 9 secondary dominants, 6 inversion/bass-tone suffixes, 12 scale-degree suffixes (`deg-0..11`), 12 solfège suffixes (`solf-0..11`) |

### 1.2 Offline Broadcast Mastering Chain (`master_clip`)

Every raw TTS MP3 passes through this deterministic DSP pipeline at `44100 Hz` mono (`f32le` PCM in memory until final MP3 encode):

1. **Tone-shaping EQ (FFmpeg):**
   - `highpass=f=75`: removes plosive rumble below 75 Hz
   - `equalizer=f=210:t=q:w=1.2:g=2.0`: adds +2.0 dB chest warmth at 210 Hz
   - `equalizer=f=3200:t=q:w=1.5:g=-3.0`: dips -3.0 dB at 3.2 kHz to reduce presence fatigue and leave room for music chords
   - `equalizer=f=6800:t=q:w=1.4:g=-2.8`: dips -2.8 dB at 6.8 kHz to tame harsh sibilance
   - `lowpass=f=9000`: smooth roll-off above 9 kHz
2. **Tight Silence Trimming:**
   - Finds first and last samples with `abs(sample) >= 0.0025`
   - Keeps `30 ms` lead-in before speech onset and `240 ms` trailing tail for natural consonant release
3. **K-Weighted Perceptual Gain Pre-Leveling:**
   - Applies standard ITU-R BS.1770 two-stage K-weighting biquads (`44.1 kHz`) over `50 ms` windows with `10 ms` hops
   - Computes relative-gated frames above `max(-42.0, ungated_db - 10.0)`
   - Blends `percep = 0.50 * KW_Act + 0.50 * KW_P85` (active speech LUFS + 85th-percentile frame LUFS) and normalizes to `TARGET_PERCEP = -18.0` before compression
4. **Broadcast Dynamics (FFmpeg):**
   - `deesser=i=0.20:m=0.30:f=0.55:s=o`: transparent HF de-essing
   - `acompressor=threshold=0.115:ratio=2.8:attack=3:release=85:knee=2.0:detection=peak:makeup=1`: peak compression (`2.8:1`, 3 ms attack, 85 ms release)
5. **Two-Pass Closed-Loop Limiting:**
   - Runs 2 passes of `measure -> gain to -18.0 -> alimiter` with `limit=0.501` (~`-6 dBFS`), `attack=4`, `release=60`
   - Applies a final fine trim (clamped to `[-0.56, 0.56]`) if residual `|TARGET_PERCEP - p_end| > 0.03`
   - Final decoded voice clips measure ~`-18.45` Percep LUFS with peaks between `-8.6` and `-6.4 dBFS`
6. **Fades, Guard Silence & Encode:**
   - Raised-cosine fade-in: `25 ms`
   - Raised-cosine fade-out: `160 ms`
   - Appends `60 ms` of zero-filled guard silence
   - Encodes via `libmp3lame` at `128k`, mono, `44100 Hz`

### 1.3 Runtime Playback & 2-Clip Chaining

- `src/audio/voiceClips.ts` maps normalized spoken phrases to `public/voice/<file>.mp3?v=VOICE_CLIPS_VERSION` (currently `'10'`).
- Base chord clips (`"One"`, `"Five seven"`, `"Five seven of four"`, etc.) and suffix clips (`inv-1..3.mp3`, `bass-{3,5,7}.mp3`, `deg-0..11.mp3`, `solf-0..11.mp3`) are fetched and decoded once by `AudioBufferAnnouncer` (`src/engine/audioAnnouncer.ts`). Note that the solfège clips use phonetic English spellings (`"over dough."`, `"over dee."`, `"over ray."`, `"over ree."`, `"over me."`, `"over fah."`, `"over fee."`, `"over soul."`, `"over see."`, `"over lah."`, `"over tay."`, `"over tea."`) in `scripts/generate_voice_clips.py` so `en-US-AvaNeural` pronounces every musical syllable accurately while runtime phrase lookup maps `"over do"`..`"over ti"`.
- When announcing an inverted chord, `getVoiceClipUrlsForPhrase` returns `[baseUrl, suffixUrl]` and `AudioBufferAnnouncer` schedules the suffix clip `advanceSec = max(0.15, (baseBuf.duration - CHAIN_OVERLAP_SEC) / rate)` after the base clip, where `CHAIN_OVERLAP_SEC = 0.19` trims the trailing fade and guard silence for a seamless spoken cadence.

### 1.4 Voice Commands & Pitfalls

```bash

python3 scripts/generate_voice_clips.py --verify

# List all slugs and spoken texts
python3 scripts/generate_voice_clips.py --list

# Regenerate specific clips cleanly
```

**Checklist when adding or updating a voice clip:**
1. Generate/master into `public/voice/<slug>.mp3` via `scripts/generate_voice_clips.py`.
2. Listen directly to the generated MP3 before committing! Watch out for TTS homograph traps such as musical `"bass"` (`/beɪs/`) vs. fish (`/bæs/`), abbreviated Roman numerals, or clipped initial plosives.
3. Update `PHRASE_TO_FILENAME`, `ALL_VOICE_CLIP_TEXTS`, and (if suffix) `INVERSION_SUFFIX_KEYS` in `src/audio/voiceClips.ts`, plus `VOICE_CLIPS` in `scripts/generate_voice_clips.py`.
4. Bump `VOICE_CLIPS_VERSION` in `src/audio/voiceClips.ts` so browsers and CDN caches fetch updated `.mp3` assets immediately.

### 2.2 The Three Sample-Processing Pipelines

1. **Choir & Remote Sustained Packs (`satb-choir`, `warm-strings`, `pipe-organ`):**
   - Source FluidR3_GM clips sustain from ~`0.25s` to ~`2.85s`, which is shorter than slow chord holds at 60 BPM (`4.0s`).
   - Takes `head = [0.08s..2.75s]` (choir) or `[0.06s..2.75s]` (strings/organ) and splices `body = [0.65s..2.85s]` via a `0.65s` equal-power sine/cosine crossfade (`cos(pi*t/2)` / `sin(pi*t/2)`), yielding ~`4.2-4.8s` of continuous sustain with no loop click.
   - Normalizes K-weighted LUFS measured across steady sustain `[0.5s..4.0s]` plus a gentle register tilt (`-1.2 dB` for MIDI >= 72, `-0.5 dB` for >= 64, `+0.7/+0.8 dB` for <= 44) so high soprano notes do not pierce and bass anchors stay warm.
   - Applies raised-cosine `25 ms` fade-in and `60 ms` fade-out.
2. **Remote Struck / Plucked Packs (`grand-piano`, `concert-harp`):**
   - Trims leading silence at threshold `0.002` keeping `4 ms` pre-roll before transient onset, capped to `max_dur` (`3.8s` / `3.6s`).
   - Measures K-weighted LUFS over the attack + early body window (`1.4s` piano, `1.2s` harp), applies register tilt (`-1.0 dB` >= 72, `-0.4 dB` >= 64, `+0.6 dB` <= 44), and clamps gain at peak `0.90`.
   - Applies a tight `3 ms` de-click fade-in and `260 ms` tail fade-out.
3. **Local `tonejs-instruments` / Movemental Packs (`french-horn`, `chamber-cello`, `harmonium`, `clean-guitar`, `nylon-guitar`):**
   - Trims leading silence relative to sample peak (`thresh_ratio = 0.012`, `4 ms` pre-roll).
   - **Sustained (`make_sustained_adaptive`):** Scans `50 ms` RMS windows starting at `0.8s` to find where healthy sustain falls below `32%` of early peak RMS (minimum `1.6s` usable body), then iteratively equal-power crossfades (`0.35s` crossfade) the steady interior `[0.55s .. body_end - 0.08s]` up to `4.22s`, finished with `8 ms` fade-in and `180 ms` fade-out.
   - **Decaying (`make_decaying`):** Caps duration to `max_dur` (`3.8s` clean guitar, `3.4s` nylon guitar) with `3 ms` fade-in and `280 ms` fade-out.
   - Normalizes `-42 dB`-gated active `50 ms` frame RMS LUFS to each pack's `target_lufs`, capped tightly by `peak_ceil` (`0.60-0.75`).

### 2.3 Runtime Web Audio Conditioning

Processed MP3s are further shaped in real time by `src/audio/sampleBank.ts`, `src/audio/choirSamples.ts`, `src/audio/instruments/sampledVoices.ts`, and `src/audio/instruments/satbChoir.ts`:

- **Pitch selection:** Nearest anchor MIDI (`playbackRate = 2 ^ ((targetMidi - anchorMidi) / 12)`), keeping pitch shifts within ~+/-1.5 to +/-2.5 semitones for natural formants.
- **Sustained hardware looping:** Sustained packs (`sustained: true`) and `satb-choir` enable `AudioBufferSourceNode.loop = true` between `loopStart = min(0.8, max(0.2, duration * 0.2))` and `loopEnd = max(loopStart + 0.5, duration - 0.35)` so arbitrarily slow chord holds never cut off early.
- **Per-register lowpass polish (`Q = 0.5`):** Bass notes (`role === 'bass'`) use a tighter cutoff (`bassCutoffHz`: `1900-3400 Hz`, `2600 Hz` choir) while upper voices open up (`upperCutoffHz`: `3400-7600 Hz`, `5200 Hz` choir).
- **Level calibration & envelopes:** Each voice multiplies `peakGain * gainBoost` (`1.9` harmonium up to `2.25` grand piano / nylon guitar; `2.1` choir), uses custom `attackSec` (`0.004-0.22s`) and `defaultReleaseSec` (`0.34-0.56s`), and applies gentle rolled strums/arpeggios via `rollStepSec` (`0.009s` piano, `0.014s` clean guitar, `0.018s` nylon guitar, `0.024s` concert harp).
- **Melody bus routing (`role === 'melody'`):** Melody notes route through `melodyBus -> melodyLevelGain -> voicePocketEq` (bypassing `warmthFilter` so the top line cuts cleanly above chord accompaniment), scale independently with `MELODY_COUNT_SCALE = 0.58`, and use brighter/tighter attack, release, and lowpass shaping than chord voices.
- **Offline graceful fallback:** If sample assets are not yet decoded or offline, sustained packs fall back to `Velvet Pad`, struck/plucked packs fall back to `Felt Piano`, and `SATB Choir` falls back to its Csound Appendix D multi-band formant synthesizer.

## Part 3: Runtime Mastering Chain & Community Wavetables

### 3.1 Native Mastering Chain (`src/audio/mastering.ts`)

Because Paws Off runs unattended in a pocket on mobile browsers, `MasterOutputChain` uses 100% native Web Audio nodes (zero `AudioWorklet` 128-sample render thread risk under iOS background throttling) to lift integrated output loudness cleanly without clipping or speaker buzz. The default `'auto'` setting performs best-effort output detection (Bluetooth `outputLatency >= 100 ms`, exposed `audiooutput` labels without requesting mic permissions, and mobile vs. desktop form factor) and can be manually overridden in **Advanced settings**:

| Stage | `Phone Speaker` | `Headphones` | Notes |
| --- | --- | --- | --- |
| Sub-bass High-Pass | `105 Hz` (`Q = 0.707`) | `30 Hz` (`Q = 0.707`) | Protects small phone drivers from sub-bass excursion waste |
| Parallel Bass Exciter | `0.26` mix (`140-440 Hz`, `4x` asymmetric shaper) | `0.0` (bypassed) | Synthesizes warm 2nd harmonics pre-compressor for missing-fundamental pitch clarity |
| Presence & Air EQ | `+1.2 dB @ 2.4 kHz`, `-1.0 dB @ 7.5 kHz` | `0 dB` | Improves small-speaker intelligibility without piercing high-frequency fatigue |
| Voice Presence EQ | `+2.2 dB @ 2.8 kHz` (`Q = 1.1`) | `0 dB` | Restores spoken-answer articulation on phone speakers |
| Loudness Drive | `1.68` (`+4.5 dB`) | `1.45` (`+3.2 dB`) | Calibrates full summed mix evenly without changing relative slider balances |
| Glue Compressor | `-15 dB`, `2.4:1`, `18 ms / 200 ms` | `-13 dB`, `2.0:1`, `22 ms / 220 ms` | Cohesive musical bus density without pumping |
| Transparent Soft Clipper | Linear `<= 0.78`, C1 `tanh` to `0.92`, `4x` oversample | Same | Zero coloration below `-2.16 dBFS`, smooth rounding on transient peaks |
| Brickwall Safety Limiter & Trim | `-1.8 dB`, `20:1`, `1 ms / 80 ms`, trim `0.89` (`-1.0 dBFS`) | Same | Leverages native ~6 ms lookahead and preserves inter-sample DAC headroom |

### 3.2 Pure Web Audio Wavetables (`src/audio/instruments/wavetables.ts`)

Six pure Web Audio instruments (`wurlitzer`, `juno-poly`, `jazz-organ`, `glass-celesta`, `harpsichord`, `analog-brass`) use compact 32-harmonic Fourier tables (>99.88% spectral energy preserved, zero external sample fetch) derived from Google Chrome Labs [`web-audio-samples`](https://github.com/GoogleChromeLabs/web-audio-samples) (`Wurlitzer_2`, `Organ_2`, `Chorus_Strings`, `Twelve_OpTines`, `Brass`, `Twelve String Guitar 1`, Apache License 2.0), alongside band-limited 20-harmonic mathematical tables (`WARM_SAW_WAVETABLE`, `PULSE_25_WAVETABLE`).
